# OpenEmpiric v0.97

## First-User Path

OpenEmpiric v0.97 focuses on making the first managed OpenCode session direct, safe, and repeatable.

The recommended install path includes semantic retrieval support:

```bash
uv tool install "git+https://github.com/xpajonx/openempiric.git#subdirectory=packages/oem-knowledge[semantic]"
```

Run `oem setup opencode` once for workstation registration, then use `oem run opencode` for normal project work.

`oem run opencode` now bootstraps project-local `.oem/` memory, restores context, refreshes the project OEM skill, and starts the managed session without asking users to run internal lifecycle commands.

Workstation setup stays explicit. `oem run opencode` does not silently rewrite global OpenCode JSONC; if OpenCode registration is missing or broken, the user path remains `oem setup opencode`, then rerun `oem run opencode`.

## Retrieval Defaults

Retrieval now defaults to `auto`.

When semantic support is installed, OpenEmpiric uses hybrid retrieval. Without semantic support, it falls back to BM25 so lightweight installs still work. Installing without `[semantic]` is best treated as an advanced BM25-only path.

## Runtime Cleanup

This release also continues the redesign work under the hood: a more modular CLI, service-oriented runtime internals, a custom SQLite vector store, a thinner OpenCode plugin, and package-owned UI rendering.
