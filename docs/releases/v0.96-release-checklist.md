# OpenEmpiric v0.96 Release Readiness Checklist

This document tracks readiness validations before tagging and releasing v0.96.

---

## 1. Runtime Layer
- [x] **Auto-init**: Fresh workspaces auto-bootstrap `.oem` structure on first agent launch.
- [x] **Auto-recovery**: Unfinished or crashed sessions are detected and can be committed or aborted safely.
- [x] **Context restoration**: Goals and active concepts are compiled and injected automatically on startup.
- [x] **Session commit**: conversation transcripts are parsed, reflected on, and committed on agent process exit.
- [x] **Reflection fallback**: Graceful degradation to basic metrics occurs if reflection fails or gets cut off.
- [x] **Outcome tracking**: Outcome metrics and goal satisfaction values are successfully written to `outcomes.jsonl`.

---

## 2. Reliability & Resilience
- [x] **Search fallback**: Vector DB errors are caught, downgrading to keywords or returning empty results instead of crashing the search tool.
- [x] **Context fallback**: File read errors degrade to minimal safe rules prompts.
- [x] **Plugin health checks**: `oem doctor` accurately identifies missing symlinks or broken plugins.
- [x] **Recovery tests**: Auto-recovery code paths have active test suite coverage.

---

## 3. Agent-First Contract
- [x] **No lifecycle instructions**: Manifests and instructions do not mention `knowledge_session_start` or `knowledge_session_commit`.
- [x] **No task steering**: Injected context does not include steering commands (e.g. `continue`, `resume`, `execute`).
- [x] **Memory is context**: Prior work targets are presented as historical context under topic or questions.
- [x] **Search optional**: The search tool is framed as optional, not as an immediate run instruction.

---

## 4. Documentation
- [x] **README updated**: Replaced lifecycle taxonomy with simplified commands taxonomy and updated onboarding guide.
- [x] **Adapter docs updated**: Specifications revised to specify runtime ownership of the session lifecycle.
- [x] **Release notes updated**: Created `v0.96.md` notes highlighting the agent-first architectural update.
