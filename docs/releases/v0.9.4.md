# OpenEmpiric v0.94

OpenEmpiric is an event-sourced knowledge runtime that helps coding agents accumulate, organize, and evolve knowledge across sessions.

This release introduces the first complete knowledge learning loop:

Experience
→ Knowledge
→ Retrieval
→ Outcome
→ Fitness
→ Promotion

Highlights:

* Outcome Tracking
* Knowledge Fitness Engine
* Knowledge Health Dashboard
* Outcome-Based Concept Promotion
* Confidence-aware status transitions
* needs_review lifecycle state
* Shared schema generation
* Runtime-native retrieval
* 54 passing tests

OpenEmpiric remains experimental.

The primary goal of this release is validating a simple question:

Can accumulated knowledge become genuinely useful over time?

We are actively looking for testers, contributors, and feedback from users of coding agents—not only OpenCode users.
